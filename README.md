# Система управления рестораном «STTV»

Данный проект представляет собой WPF-приложение для автоматизации бизнес-процессов ресторана. Разработано в рамках учебной практики УП.01.01 по теме курсового проекта: «Проектирование и разработка базы данных для системы управления рестораном».

## Технологический стек
*   **Язык программирования:** C# (.NET)
*   **Интерфейс:** WPF (Windows Presentation Foundation), XAML
*   **Архитектурный паттерн:** MVVM (Model-View-ViewModel)
*   **База данных:** Microsoft SQL Server
*   **ORM:** Entity Framework (подход Database First, EDMX)
*   **Библиотеки для экспорта:** ClosedXML (.xlsx), DocX (.docx), QuestPDF (.pdf)

## Структура базы данных
База данных включает в себя следующие основные таблицы:
*   `Users` — пользователи системы (Администраторы, Официанты, Повара).
*   `Dishes` — справочник блюд (меню ресторана).
*   `Orders` — заголовки заказов (кто, на какой столик и когда сделал заказ).
*   `OrderItems` — состав заказа (связь заказа с конкретными блюдами).
*   `Tables` — справочник столиков ресторана.
*   `OrderStatuses` — справочник статусов заказов (Новый, Готовится, Подан, Оплачен).

## 👥 Роли и функционал
В приложении реализовано разграничение прав доступа:
1.  **Администратор:**
    *   Полный доступ ко всем разделам.
    *   CRUD (создание, чтение, обновление, удаление) для пользователей, блюд и заказов.
    *   Просмотр статистики и экспорт отчетов (Excel, Word, PDF).
2.  **Официант:**
    *   Просмотр меню блюд.
    *   Формирование заказов (корзина с выбором столика).
    *   Просмотр только своих заказов.
3.  **Повар:**
    *   Просмотр всех заказов ресторана.
    *   Изменение статуса готовности заказа.

**Общие функции:**
*   Авторизация и регистрация (пароли хранятся в виде хэшей SHA256).
*   Защита от подбора паролей (капча после 3 неверных попыток).
*   Смена пароля пользователя.
*   Смена цветовой темы приложения (светлая/темная) с сохранением выбора в БД.
*   Каскадное удаление данных.
*   Поиск, сортировка и фильтрация в таблицах.

## Структура решения
*   `ResturantApp.sln` — файл решения Visual Studio.
*   `db/` — каталог для скриптов базы данных.
    *   `schema.sql` — SQL-скрипт для создания базы данных, таблиц, связей и заполнения тестовыми данными.
*   `res/` — каталог для ресурсов приложения (иконка, изображения).
*   `Resturant/` — исходный код WPF-приложения:
    *   `Models/` — модели данных (сгенерированы из БД).
    *   `Services/` — бизнес-логика (авторизация, хэширование).
    *   `ViewModels/` — логика представлений.
    *   `Pages/` — страницы приложения (Меню, Заказы, Пользователи).
    *   `App.xaml` — глобальные стили и ресурсы.

## Как запустить проект
1.  Клонируйте репозиторий на локальный компьютер.
2.  Откройте файл `db/schema.sql` в SQL Server Management Studio (SSMS) и выполните его для создания базы данных.
3.  Откройте решение `ResturantApp.sln` в Visual Studio 2022.
4.  Проверьте строку подключения к базе данных в файле `App.config` (убедитесь, что указан ваш сервер SQL).
5.  Запустите проект (F5).
